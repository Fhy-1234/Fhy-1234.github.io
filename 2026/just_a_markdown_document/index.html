不就是Markdown文档吗

如果你不知道Markdown文档（.md）的语法，可以参考这篇文章。

Markdown 是一种轻量级标记语言，创始人为约翰·格鲁伯（John Gruber）。它允许人们使用易读易写的纯文本格式编写文档，然后转换成有效的 XHTML（或者HTML）文档。

由于 Markdown 的轻量化、易读易写特性，并且对于图片，图表、数学式都有支持，许多网站都广泛使用 Markdown 来撰写帮助文档或是用于论坛上发表消息。如 GitHub、Reddit、Diaspora、[Stack Exchange](https://baike.baidu.com/item/Stack Exchange/13777796?fromModule=lemma_inlink)、OpenStreetMap、SourceForge、简书等，甚至还能被使用来撰写电子书。

因为人工智能基础课程讲了.md的语法（虽然这些我早就会了），不过因为太无聊，于是就写了这篇文章…虽然这种教程网上已经很多了

人工智能基础对我来说就是水课，不过对于没接触过电脑的同学应该有一些用处吧。第一节课甚至教你用金山打字通练习打字，然后教你练习使用豆包、Deepseek之类的，老师对于最新的Windows系统还停留在Win10… 但是因为是必修课，又不得不上

基本语法

1.标题

### 1到6个井号可以设置几级标题(3级标题) 要注意井号和文字中间需要空格，井号的数量对应不同级别的标题。比如“基本语法”就是二级标题。

2.加粗

**文字两侧各加两个星号是加粗**

3.斜体

*文字两侧只加一个星号就是斜体*

4.下划线

<u>文字两侧加入这样的格式就可以添加下划线</u> ，下划线英文是underline，所以可以记缩写是U，然后加入<>。开始仅为U，结束需要加入斜杠，即**/u**表示结束。

5.表格 时间 事件 备注
10:30-12:10 人工智能基础 不想上课
13:10-14:15 学院合唱排练 唱力竭了
14:30-18:10 书法基础 又是一下午的课
表格的格式 |列1类型|列2类型|列3类型|

|时间|事件|备注| 这样就会创建一个只有1行的表格了。
